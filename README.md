# ALTITUDE — Himalayan Treks

**Adventure, minus the guesswork.**

Altitude is a premium, responsive marketing website for a Himalayan trekking company that organises guided treks for small groups of 6–10 people. The website combines outdoor photography, elegant typography, interactive animations, and a safety-focused approach to trekking.

## Features

- **Immersive Hero Section:** Layered mountain ridges and parallax scrolling effects.
- **Featured Treks:** Explore five Himalayan treks: Kedarkantha, Hampta Pass, Valley of Flowers, Brahmatal, and Goechala.
- **Light and Dark Mode:** Switch between themes with saved preferences.
- **Scroll-Driven Animations:** Interactive effects powered by GSAP and ScrollTrigger.
- **Smooth Scrolling:** Lenis integration for a fluid browsing experience.
- **Safety and Planning:** Highlights local guides, small groups, permits, emergency evacuation cover, and transparent pricing.
- **How It Works:** A four-step guide from choosing a trek to reaching the summit.
- **Testimonials and Gallery:** Trekker stories and outdoor photography.
- **Interactive FAQ:** Expandable answers to common trekking questions.
- **Responsive Design:** Layouts adapted for desktop, tablet, and mobile screens.
- **Newsletter Interface:** An email subscription form ready for mailing-list integration.
- **Accessibility:** Semantic sections, keyboard focus indicators, image descriptions, and reduced-motion support.

## Design Philosophy

Altitude follows a premium outdoor-editorial aesthetic rather than a conventional SaaS layout.

- Warm paper backgrounds and forest-green surfaces.
- Ember-orange accents for important actions.
- Expressive serif headlines and clean sans-serif body text.
- Asymmetric layouts, generous whitespace, and large photographic sections.
- Subtle animations that respect reduced-motion preferences.
- Consistent spacing, rounded corners, and carefully selected typography.

## Getting Started

### Prerequisites

- A modern web browser.
- Git installed on your computer.
- Visual Studio Code or another code editor.

### Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Open the project in Visual Studio Code.

4. Open `index.html` in your browser or use the Live Server extension.

**Note:** The current deployed implementation uses HTML, CSS, JavaScript, and browser-loaded libraries. A complete React, TypeScript, and Tailwind CSS setup would require the corresponding project configuration and build tools.
